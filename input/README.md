# input/

Drop everything you've already gathered or studied about a topic here — PDFs, notes,
transcripts, articles, photos, links. Use one subfolder per topic if you like, e.g.
`input/persian-cheetah/`.

The agent reads everything here first, then does its own web research on top (to verify,
update, and fill gaps), and compiles it into `output/<slug>-research.md`.

If this folder is empty for a topic, the agent does a deep independent research pass instead.
