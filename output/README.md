# output/

Per topic, the agent writes **exactly three Markdown files** here:

- `<slug>-prompts.md`  — ★ the most important file: per-shot AI-video prompts (5–8s each),
  scene detail, and the narration for each sequence. English prompts.
- `<slug>-scenario.md` — the sectioned scenario, bilingual (EN + FA), translated into
  filmable visual detail.
- `<slug>-research.md` — the factual/scientific backbone with sources (when research is done).

No other files. See `../WORKFLOW.md` for the full operating brief.

> Subfolders dated before this convention (naghd/, negaareh/, prompt/, senaario/, shakhsiat/,
> storybord/, sample-pardeye-akhar/, …) are legacy output from the earlier pipeline and are
> kept as-is. The streamlined pipeline writes the 3 files above directly into `output/`.
