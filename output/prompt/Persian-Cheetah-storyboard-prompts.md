# Persian Cheetah · Storyboard Panel Prompts (pencil & ink)
## یوز ایرانی · پرامپتِ پنل‌های استوری‌بورد

> **Secondary deliverable.** Per-shot **still-image** prompts for pencil/ink storyboard panels.
> **Use for:** pitch decks, festival submissions, director's portfolio, planning sessions, location-scout briefs.
> **Engines:** Bing Image Creator (DALL·E 3), Leonardo AI, Krea AI, Flux Schnell (fal.ai / HuggingFace), Ideogram.
> **Aspect ratio:** all panels 16:9. **Style baseline:** loose pencil under-drawing + ink line, light grey wash, single warm accent (ochre or red) for emphasis where appropriate. Hand-drawn storyboard aesthetic — *not* finished concept art.

---

## GLOBAL STYLE BLOCK (paste at top of every prompt)

> *Storyboard panel, 16:9 letterbox frame with clean black border, hand-drawn pencil-and-ink illustration style, loose graphite under-drawing visible, confident ink linework on top, light grey marker wash for shadow areas, sparse use of a single warm ochre accent only where indicated, white paper background with subtle texture, no color saturation, no photoreal rendering, classic film-school storyboard aesthetic, in the tradition of Hayao Miyazaki, Mamoru Hosoda, and Western pre-production boards (cf. Spielberg's Empire of the Sun boards), 16:9.*

**Global negative prompt:**
> `--no photoreal, 3D render, oversaturated color, anime stylization, manga, cartoon faces, watermark, text in image, blurred lines, AI-generic art, illustration brush`

## WHERE TO PASTE EACH PROMPT

| Engine | URL | Notes |
|---|---|---|
| **Bing Image Creator** | bing.com/create | Free, generous daily quota, DALL·E 3. Strong on text-in-image (title cards). |
| **Leonardo AI** | leonardo.ai | Free daily tokens. Good for stylized illustration. Use "Realistic Vision" or "DreamShaper" model. |
| **Krea AI** | krea.ai | Free tier. Real-time generation, fast iteration. |
| **Flux Schnell on fal.ai** | fal.ai/models/fal-ai/flux/schnell | Free inference. Best quality / cost on Flux pipeline. |
| **Ideogram** | ideogram.ai | Free tier. **Strongest for title cards and pull-quote cards** (text-in-image is its specialty). |
| **HuggingFace Spaces** | huggingface.co/spaces (search "flux schnell") | Free, no signup required for some Spaces. |

**Workflow recommendation:**
1. Use **Ideogram** for all title cards and pull-quote cards (Panels 1.5, 1.6, 5.02–5.05 name cards, 7.3 final card).
2. Use **Flux Schnell** for all pencil-and-ink panel illustrations (everything else).
3. Use **Bing Image Creator** as a free backup when daily quotas are exhausted.
4. **Iterate per panel** until the style baseline holds — pencil-and-ink, sparse warm accent, no photoreal contamination.

## STYLE CONSISTENCY CHECKLIST

Before accepting any panel into the storyboard binder:

- [ ] 16:9 letterbox frame with clean black border?
- [ ] Pencil-and-ink hand-drawn aesthetic — not photoreal, not 3D, not anime?
- [ ] Light grey wash only for shadow areas — no full color saturation?
- [ ] Warm ochre accent only where specified — never elsewhere?
- [ ] Iranian plateau elements (gravel, Artemisia, basalt, snow-dusted ridges) — never African savanna?
- [ ] If a cheetah is in the panel: paler coat, longer legs, thicker neck ruff, tear-stripes?
- [ ] Captions placed in the margin (not inside the frame)?
- [ ] No watermark, no text inside the frame, no model artifacts?
